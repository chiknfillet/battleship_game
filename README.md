## Battleship

Battleship is a web-based implementation of the classic naval strategy game, built with JavaScript, HTML, and CSS. The player attempts to find and sink the hidden fleet placed by the computer AI. Simple, responsive, and playable in any modern browser.

🎯 Single-player vs. Computer AI — Computer randomly places ships and responds to player shots.

🗺️ Interactive Grid — Click to fire at cells; hits and misses are visually indicated.

♟️ Ship Types — Standard fleet (carrier, battleship, cruiser, submarine, destroyer).

🔁 Easy Reset & Replay — Start a new game with a single click.

[▶️ Play Live Demo](https://chiknfillet.github.io/battleship_game/)
